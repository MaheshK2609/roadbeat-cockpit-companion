# Roadbeat Cockpit Companion

Analyze all four uploaded reference images. Use them as visual inspiration for a single, unified automotive infotainment dashboard.

Use the fourth image as the primary reference for the digital instrument cluster, including the two circular RPM and speed gauges, central road visualization, gear indicator, and vehicle warning icons.

Take the dark premium styling, blue glow effects, navigation, music player, and vehicle status elements from the other references.

Build a functional, full-screen 1920×1080 web dashboard using React, TypeScript, and Tailwind CSS.

The dashboard must contain real HTML/CSS/SVG interface elements, not a background screenshot. Use realistic simulated vehicle data for now. Make the gauges, navigation tabs, media controls, and diagnostic alerts interactive.

Start by implementing the complete main dashboard screen. Do not add backend integration yet. Prioritize visual accuracy, spacing, typography, and a polished automotive HMI appearance.
